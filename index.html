阅读增强4

每日书摘v1.1.0推荐

随机弹出一句书摘。可以在设置里塞自己的句子，存在插件自己的存储里。
notify
命令：来一句书摘

随机抽书v1.0.0

从书架里随机抽一本，选择困难的时候用。
notifybooks
命令：随机抽一本 / 抽三本备选

专注计时v1.0.0推荐

番茄钟：专注一轮、休息一下，把今天读了几轮记下来。
uinotifysettings
命令：开始专注 / 打开计时器 / 今天读了几轮

书摘本v1.0.0推荐

随手记下句子，随机抽一句、一键复制，都放在插件自己的存储里。
uinotifyclipboard
命令：打开书摘本 / 随机来一句

统计2

阅读时钟v1.1.0推荐

统计今天读了多久、翻了几本书。设置里可以给每天定个目标。
notify
命令：今日阅读统计 / 清零今天的记录

阅读目标v1.0.0推荐

给每天定一个阅读时长目标，记录连续天数，完成时提醒你。
uinotifysettings
命令：打开阅读目标 / 今天读了多少

界面2

阅读面板v1.0.0推荐

用插件界面展示书架概览，支持一键刷新和随机推荐。
uibooksnotify
命令：打开阅读面板

排版预设v1.0.0

一键切换紧凑、舒适、大字三种排版，不用再逐个拖滑块。
uisettingsnotify
命令：打开排版预设 / 切到紧凑排版 / 切到舒适排版 / 切到大字排版
